# JobFit

Türkiye odaklı AI destekli iş başvuru asistanı MVP.

## MVP özellikleri
- CV metni + iş ilanı analizi
- JobFit 0-100 eşleşme skoru
- Güçlü eşleşen anahtar kelimeler
- Eksik / CV'de görünmeyen anahtar kelimeler
- Başvur / önce CV'yi güçlendir önerisi
- API gerektirmeden çalışan demo
- Mobil uyumlu arayüz

## Lokal çalıştırma
```bash
npm install
npm run dev
```

## Vercel
GitHub reposunu Vercel'e bağla ve deploy et. Ek environment variable gerekmiyor.
